# Bulletproofing a discipline skill

The branch of [`writing-for-agents`](SKILL.md) for one failure class: the agent knows the rule and skips it under pressure. The fix is not clearer prose — it is closing the loopholes, in the words the agent will actually use to excuse itself.

Do not reach for this when the output merely comes out the wrong shape: a prohibition makes that worse. Check the form table in [`SKILL.md`](SKILL.md) first.

## Close every loophole by name

State the rule, then forbid the workarounds it invites. A rule without its workarounds named is an invitation:

> Delete the code. Don't keep it as a reference. Don't adapt it. Delete means deleting.

An agent under pressure reaches for the nearest available exit. A named exit is no longer available.

## Violating the letter is violating the spirit

Put this near the top of any discipline skill. It retires a family of arguments before they are made: "I followed the spirit", "the rule doesn't really apply here", "this case is different".

## Build the table from real excuses

A rationalization table earns its place only when populated from what agents actually said, not from what you imagine they would say. Run the skill's scenarios without the skill first, record the excuses verbatim, then answer them:

| Excuse | Reality |
| --- | --- |
| "I already tested it manually, so I don't need the automated check." | Manual testing happened once, on one path, and left no evidence. The check is the evidence. |

## Red flags

Close the skill with a short list of the exact thoughts that mean stop — "I already tested it manually", "this case is different because…", "I'll clean it up after". These are recognition cues, so quote the thought rather than describing the mistake.

## The description carries the symptom

When the violation is predictable, put its symptom in the description too. The pointer has to fire when the agent is *about to* violate, not once it has already decided to.

## Verify it holds

Re-run the scenario after each countermeasure and look for a new excuse; two or three rounds is normal. The skill holds when the agent complies, cites the skill as its reason, and reports that the temptation was real but the rule was clear — and stays compliant across trials. A hybrid invention, or asking permission while arguing toward the violation, means a loophole is still open. The protocol is in [`TESTING-SKILLS.md`](TESTING-SKILLS.md); the evidence bar is uniform compliance under combined pressure.
